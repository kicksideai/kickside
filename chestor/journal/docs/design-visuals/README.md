# Journal design boards

These are clean-sheet, high-fidelity direction boards for the rebuilt Journal.
They are not screenshots of implemented UI and preserve no legacy Journal
components. Platform theme/access/deep-link conventions remain implementation
constraints.

1. [`01-context-graph-workspace.png`](01-context-graph-workspace.png) — bounded
   graph workspace with persistent where/why/trust/next context, agent cursors,
   provenance inspector, contradictions, and changes since checkpoint.
2. [`02-hybrid-search-timeline.png`](02-hybrid-search-timeline.png) — explained
   hybrid recall with exact prefilters, score components, inference labeling,
   temporal watermarks, provenance, and time scrubbing.
3. [`03-force-graph-outline-tree.png`](03-force-graph-outline-tree.png) —
   first-class force-directed exploration paired with a precise canonical
   outline tree, bounded windows, clustering, pins, aggregates, and cursors.
4. [`04-deep-organization-folded-learning.png`](04-deep-organization-folded-learning.png)
   — deep/four-level organization advice and failure-preserving branch folding,
   with distilled learning, reusable constraints, evidence, successor links,
   and full branch recovery.

The prompts deliberately require readable production UI, a light Chestor-native
palette, status encoded by icon/shape/label as well as color, explicit
completeness and projection state, no full-graph client load, and no task table,
Kanban board, or legacy Journal shell.
