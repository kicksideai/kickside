# Chestor Journal UI specification

The previous task-first Journal UI specification is retired. None of its shell,
tabs, views, components, information hierarchy, or interaction structure is a
compatibility requirement for the rebuild.

The clean-sheet human and agent interface is defined by
[`../journal/docs/canonical-graph-architecture.md`](../journal/docs/canonical-graph-architecture.md).
Only platform-level Chestor contracts are retained: Workspace hosting,
access-control integration, theme tokens, deep-link conventions, projection
wakeups, and accessibility behavior.
